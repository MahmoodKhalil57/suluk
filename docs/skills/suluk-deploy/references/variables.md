# Variables & Constants

## `providers`
The provider registry. Add new targets here; the interface is the contract.
```ts
const providers: Record<string, DeployProvider>
```

## cloudflare

### `cloudflare`
The Cloudflare deployment provider.
```ts
const cloudflare: DeployProvider
```

```ts
const DEFAULT_COMPAT_DATE: "2026-06-01"
```
