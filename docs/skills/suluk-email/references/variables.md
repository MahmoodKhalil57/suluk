# Variables & Constants

## render

### `DEFAULT_EMAIL_STRINGS`
English fallbacks for the chrome strings, so a render works before any catalog is authored.
```ts
const DEFAULT_EMAIL_STRINGS: Catalog
```

## templates

### `TEMPLATE_STRINGS`
English defaults for every template string, so the set is usable before any catalog is authored.
```ts
const TEMPLATE_STRINGS: Catalog
```
