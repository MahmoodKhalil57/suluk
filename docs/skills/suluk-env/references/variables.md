# Variables & Constants

## crypto

### `SCHEME`
The cipher/key scheme tag embedded in keys + tokens. Bump if the construction ever changes.
```ts
const SCHEME: "mlkem768"
```

## envfile

### `PUBLIC_KEY_NAME`

```ts
const PUBLIC_KEY_NAME: "SULUK_PUBLIC_KEY"
```

### `PRIVATE_KEY_NAME`
```ts
const PRIVATE_KEY_NAME: "SULUK_PRIVATE_KEY"
```
